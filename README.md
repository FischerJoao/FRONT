
# 📱 CRUD com React Native (Expo) e MongoDB

Este projeto é um aplicativo de cadastro de usuários utilizando **React Native com Expo no frontend** e **Node.js com MongoDB no backend**.

---

## 🚀 Como rodar o projeto

### ▶️ Frontend (React Native - Expo)

1. Acesse a pasta do frontend:
   ```bash
   cd front
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o projeto:
   ```bash
   npm run start
   ```
   > Ou, caso esteja usando npx:
   ```bash
   npx expo start
   ```

---

### 🖥️ Backend (Node.js + MongoDB)

1. Acesse a pasta do backend:
   ```bash
   cd server
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Configure as variáveis de ambiente:
   - Verifique o arquivo `.env` e adicione os dados necessários, como a URL do MongoDB.

4. Inicie o servidor:
   ```bash
   npm run dev
   ```

---

## 🛠 Tecnologias utilizadas

- **Frontend:** React Native, Expo, React Native Paper
- **Backend:** Node.js, Express, MongoDB, Mongoose
